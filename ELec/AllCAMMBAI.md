| โมดูลกล้องงู (Endoscope) | USB หรือ Analog Video | ทำได้ง่ายที่สุด: กล้องงูมักใช้สัญญาณ USB (4 สาย: VCC, GND, D+, D-) หรือสายนิวทรัลอนาล็อก หากมีโมดูลกล้องงูแบบ USB สามารถต่อเข้า PC, Android (ผ่าน OTG) ได้ทันที |
| อะไหล่กล้องวงจรปิด (BLK530AI) | WiFi / Ethernet / Power | ใช้งานต่อยอดได้ทันที: บอร์ดกล้องวงจรปิดนี้เป็น Standalone IP Camera Module มีชิปประมวลผล SoC ในตัว เพียงจ่ายไฟ (ปกติ 5V หรือ 12V) และเชื่อมต่อผ่าน WiFi/LAN สามารถใช้เป็นกล้องวงจรปิด DIY, กล้องมองหลัง, หรือเชื่อมเข้ากับระบบ NVR / Home Assistant ได้เลย |
คำแนะนำสำหรับการใช้งาน
 * สำหรับ ESP32-CAM: หากต้องการเปลี่ยนกล้อง OV2640 2MP เดิม ควรซื้อโมดูลกล้องที่เป็นมาตรฐาน DVP 24-Pin ตรงรุ่น (เช่น OV3660, OV5640 แบบสายแพรยาว) ไม่สามารถนำกล้องมือถือในรูปมาบัดกรีใช้แทนได้
 * สำหรับบอร์ดกล้องวงจรปิด IP (BLK530AI): สามารถหาเคส 3D Print มาใส่ และต่อไฟใช้งานเป็นกล้อง DIY ได้ง่ายและสมบูรณ์ที่สุดในบรรดาอะไหล่ทั้งหมด
 * สำหรับกล้องมือถือเก่า: เหมาะสำหรับนำไปแกะเอาเฉพาะ เลนส์ชิ้นแก้ว มาส่องเป็นเลนส์มาโครขยายสำหรับกล้องสมาร์ทโฟน หรือเก็บเป็นอะไหล่ซ่อมมือถือรุ่นตรงกัน
