```md
ภาพรวมก่อน — Type-C มีหลายแบบมาก

ที่คนเรียกกันว่า “24 ขา” จริง ๆ คือหัว USB Type‑C แบบเต็มมาตรฐาน
ส่วน “16 ขา” ที่เห็นเว้นกลาง 2-6-2 ส่วนมากคือหัว Type-C แบบลดขา ใช้แค่ USB2.0 + ชาร์จไฟ ไม่มีเส้นความเร็วสูงครบทุกเส้น

หน้าตาหัวแบบต่าง ๆ

Type-C 24 ขา (12 บน + 12 ล่าง)

Type-C 16 ขา (8 บน + 8 ล่าง)

USB รุ่นเก่า


---

1) Type-C 24 ขา ไล่ขาแบบละเอียด

ด้านบน (A side)

ขา	ชื่อ	หน้าที่

A1	GND	ลบ / กราวด์
A2	TX1+	ส่งข้อมูลความเร็วสูง
A3	TX1-	ส่งข้อมูลความเร็วสูง
A4	VBUS	+5V ถึง +20V
A5	CC1	ตรวจสาย / PD / กลับด้าน
A6	D+	USB2.0
A7	D-	USB2.0
A8	SBU1	สัญญาณพิเศษ
A9	VBUS	ไฟบวก
A10	RX2-	รับข้อมูลความเร็วสูง
A11	RX2+	รับข้อมูลความเร็วสูง
A12	GND	กราวด์



---

ด้านล่าง (B side)

ขา	ชื่อ	หน้าที่

B1	GND	กราวด์
B2	TX2+	ส่งข้อมูล
B3	TX2-	ส่งข้อมูล
B4	VBUS	ไฟบวก
B5	CC2	ตรวจกลับด้าน
B6	D+	USB2.0
B7	D-	USB2.0
B8	SBU2	สัญญาณพิเศษ
B9	VBUS	ไฟบวก
B10	RX1-	รับข้อมูล
B11	RX1+	รับข้อมูล
B12	GND	กราวด์



---

2) ขาที่ “จำเป็น” ถ้าจะทำแค่ชาร์จ + USB2

จริง ๆ ใช้แค่:

ใช้	ขา

ไฟบวก	VBUS
กราวด์	GND
Data+	D+
Data-	D-
PD/ตรวจสาย	CC1 / CC2


ดังนั้นหัว 16 ขาเลย “ตัด” ขาความเร็วสูงออกได้


---

3) Type-C 16 ขา (2-6-2)

แบบนี้นิยมใน:

บอร์ดชาร์จ

โมดูล DIY

หัวแปลงถูก ๆ

USB2 เท่านั้น


โครงสร้าง

ด้านบน:

GND 2 ขา

กลาง 6 ขา

VBUS 2 ขา


ด้านล่างเหมือนกัน


---

ปกติขากลาง 6 ขาจะเป็น

ขา	หน้าที่

CC1	
D+	
D-	
CC2	
SBU1	
SBU2	


หรือบางรุ่นตัด SBU ออกอีก


---

4) สีสาย USB มาตรฐาน

USB2.0

สี	ความหมาย

แดง	+5V
ดำ	GND
เขียว	D+
ขาว	D-



---

USB3.0 / สายสีฟ้า

เพิ่มอีกหลายเส้น:

สีทั่วไป	หน้าที่

น้ำเงิน	TX/RX
เหลือง	TX/RX
ม่วง	TX/RX
ดำเพิ่ม	GND


แต่ “สีไม่ตายตัว” โดยเฉพาะสายจีน


---

5) Type-C กับสาย USB สีต่าง ๆ ต่อยังไง

ถ้าจะทำ USB2.0 ธรรมดา

USB เดิม	Type-C

แดง	VBUS
ดำ	GND
เขียว	D+
ขาว	D-


แล้วต้องมี:

ตัวต้านทาน 5.1k ที่ CC



---

6) ทำไม Type-C ต้องมี CC ?

เพราะ Type-C ไม่เหมือน Micro USB

มันใช้ CC เพื่อ:

เช็กเสียบด้านไหน

เช็กจ่ายไฟเท่าไร

เช็ก PD

เช็ก Fast Charge

7) ถ้าจะ “รับไฟ 5V ธรรมดา”

ต้องใส่:

CC1 → R 5.1k → GND

CC2 → R 5.1k → GND

8) แล้ว 65W ต้องใช้อะไร ?

65W = ไม่ใช่แค่ต่อ + กับ -

ถ้าได้:

ค่อยปล่อย 65W

11) สาย 65W ต้องมี E-Marker ไหม ?
```

```c
/*
 DIY SPOT WELDER
 Arduino UNO + IR2110 + MOSFET
 PSU 12V 800W

 D9  -> Gate Q1
 D10 -> Gate Q2
 D11 -> Gate Q3
 D12 -> Gate Q4

 D2 -> Fire Button
 A0 -> Potentiometer

 LCD I2C 16x2
*/

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27,16,2);

#define Q1 9
#define Q2 10
#define Q3 11
#define Q4 12

#define FIRE_BTN 2
#define POT A0

int weldTime = 10;

void setup()
{
  pinMode(Q1, OUTPUT);
  pinMode(Q2, OUTPUT);
  pinMode(Q3, OUTPUT);
  pinMode(Q4, OUTPUT);

  pinMode(FIRE_BTN, INPUT_PULLUP);

  digitalWrite(Q1, LOW);
  digitalWrite(Q2, LOW);
  digitalWrite(Q3, LOW);
  digitalWrite(Q4, LOW);

  lcd.init();
  lcd.backlight();

  lcd.setCursor(0,0);
  lcd.print("SPOT WELDER");
  delay(1000);
}

void loop()
{
  int pot = analogRead(POT);

  // ปรับเวลา 1-100ms
  weldTime = map(pot,0,1023,1,100);

  lcd.setCursor(0,0);
  lcd.print("TIME:");
  lcd.print(weldTime);
  lcd.print("ms   ");

  lcd.setCursor(0,1);
  lcd.print("READY        ");

  if(digitalRead(FIRE_BTN)==LOW)
  {
    firePulse();

    lcd.setCursor(0,1);
    lcd.print("WELDING...   ");

    delay(500);
  }
}

void firePulse()
{
  // เปิด MOSFET
  digitalWrite(Q1,HIGH);
  digitalWrite(Q2,HIGH);
  digitalWrite(Q3,HIGH);
  digitalWrite(Q4,HIGH);

  delay(weldTime);

  // ปิด MOSFET
  digitalWrite(Q1,LOW);
  digitalWrite(Q2,LOW);
  digitalWrite(Q3,LOW);
  digitalWrite(Q4,LOW);

  delay(100);
}

```
