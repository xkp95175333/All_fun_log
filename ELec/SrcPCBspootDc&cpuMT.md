พัดลม Tsunami รุ่นที่คุณมีเป็นพัดลมขนาด 120 มม. ใช้ไฟ DC 12V และกินกระแสสูงสุดประมาณ 0.34–0.37A ตามสเปคของซีรีส์ที่ใกล้เคียง (Protector 1262K และ 1266W) ซึ่งถือว่าเป็นมาตรฐานของพัดลมคอมพิวเตอร์ทั่วไป-A0157386-i.62824618.23764001015 "Tsunami Thailand")  

---

🔧 สเปคหลักของพัดลม Tsunami (รุ่น 12cm)
| รายการ | ค่า |
|--------|------|
| แรงดันไฟฟ้า (Rated Voltage) | DC 12V |
| แรงดันควบคุม (Control Voltage) | 5–13.2V |
| แรงดันเริ่มทำงาน (Start Voltage) | < 5V |
| กระแสไฟฟ้า (Rated Current) | 0.34–0.37A |
| กำลังไฟ (Power) | ~4.3W |
| รอบหมุน (Speed) | 1200–2200 RPM ±10% |
| แรงลมสูงสุด (Airflow) | 47–55 CFM |
| เสียงรบกวน (Noise Level) | 26–32 dB(A) |
| อายุการใช้งาน (Lifetime) | ~40,000 ชั่วโมง |
| ประเภท Bearing | Hydraulic Bearing |
| คอนเนกเตอร์ | 4–6 Pin (ขึ้นกับรุ่น)-A0157386-i.62824618.23764001015 "Tsunami Thailand") |

---

🔌 เรื่องสายไฟ 6 เส้น
- โดยทั่วไป พัดลมคอมพิวเตอร์มาตรฐานใช้ 4 เส้น:
  - แดง (V+) → ไฟบวก 12V  
  - ดำ (GND) → กราวด์  
  - เหลือง (Tach) → สัญญาณวัดรอบ  
  - น้ำเงิน (PWM) → สัญญาณควบคุมความเร็ว  

- รุ่น Tsunami บางตัวมี 6 เส้น เพราะรวมสายสำหรับ ARGB/RGB LED:
  - 2 เส้นสำหรับไฟ LED (V+ และ GND ของไฟ)  
  - 4 เส้นสำหรับพัดลม (ตามมาตรฐานข้างต้น)  

ดังนั้นที่คุณวัดเจอว่า “มีเส้นขีดขาวเป็น -, เส้นมีตัวหนังสือเป็น +” น่าจะเป็นคู่สายไฟเลี้ยง LED ส่วนอีก 4 เส้นคือสายพัดลมจริง ๆ

---

✅ วิธีตรวจสอบสายที่ไม่รู้
1. ใช้ มัลติมิเตอร์ วัดความต่อเนื่อง (continuity) ระหว่างสายกับวงจร LED บนพัดลม → ถ้าเจอไปที่ LED คือสายไฟเลี้ยงไฟ RGB  
2. สายที่เหลือ 4 เส้น → ต่อกับคอนเนกเตอร์พัดลมมาตรฐาน (12V, GND, Tach, PWM)  
3. ถ้าไม่แน่ใจ → ต่อเฉพาะ +12V และ GND ก่อน พัดลมจะหมุนทันทีโดยไม่ต้องใช้ Tach/PWM  

---

⚠️ ข้อควรระวัง
- อย่าใช้ไฟเกิน 12V เพราะแม้สเปคบอกว่า Control Voltage ได้ถึง ~13.2V แต่การจ่ายไฟเกินอาจทำให้มอเตอร์เสียหาย  
- กระแสสูงสุด ~0.37A → ถ้าใช้หลายตัวพร้อมกันควรตรวจสอบว่าแหล่งจ่ายไฟรองรับได้  
- ถ้าอยากใช้ฟังก์ชัน PWM หรือ ARGB ต้องมี คอนโทรลเลอร์/ฮับของ Tsunami หรือเมนบอร์ดที่รองรับ
