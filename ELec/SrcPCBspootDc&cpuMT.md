🔧 สเปคหลักของพัดลม Tsunami (รุ่น 12cm)
| รายการ | ค่า |
|--------|------|
| แรงดันไฟฟ้า (Rated Voltage) | DC 12V |
| แรงดันควบคุม (Control Voltage) | 5–13.2V |
| แรงดันเริ่มทำงาน (Start Voltage) | < 5V |
| กระแสไฟฟ้า (Rated Current) | 0.34–0.37A |
| กำลังไฟ (Power) | ~4.3W |
| รอบหมุน (Speed) | 1200–2200 RPM ±10% |
| แรงลมสูงสุด (Airflow) | 47–55 CFM |
| เสียงรบกวน (Noise Level) | 26–32 dB(A) |
| อายุการใช้งาน (Lifetime) | ~40,000 ชั่วโมง |
| ประเภท Bearing | Hydraulic Bearing |
| คอนเนกเตอร์ | 4–6 Pin (ขึ้นกับรุ่น)-A0157386-i.62824618.23764001015 "Tsunami Thailand") |

🔌 เรื่องสายไฟ 6 เส้น
- โดยทั่วไป พัดลมคอมพิวเตอร์มาตรฐานใช้ 4 เส้น:
  - แดง (V+) → ไฟบวก 12V  
  - ดำ (GND) → กราวด์  
  - เหลือง (Tach) → สัญญาณวัดรอบ  
  - น้ำเงิน (PWM) → สัญญาณควบคุมความเร็ว  

- รุ่น Tsunami บางตัวมี 6 เส้น เพราะรวมสายสำหรับ ARGB/RGB LED:
  - 2 เส้นสำหรับไฟ LED (V+ และ GND ของไฟ)  
  - 4 เส้นสำหรับพัดลม (ตามมาตรฐานข้างต้น)  

ดังนั้นที่คุณวัดเจอว่า “มีเส้นขีดขาวเป็น -, เส้นมีตัวหนังสือเป็น +” น่าจะเป็นคู่สายไฟเลี้ยง LED ส่วนอีก 4 เส้นคือสายพัดลมจริง ๆ

---

✅ วิธีตรวจสอบสายที่ไม่รู้
1. ใช้ มัลติมิเตอร์ วัดความต่อเนื่อง (continuity) ระหว่างสายกับวงจร LED บนพัดลม → ถ้าเจอไปที่ LED คือสายไฟเลี้ยงไฟ RGB  
2. สายที่เหลือ 4 เส้น → ต่อกับคอนเนกเตอร์พัดลมมาตรฐาน (12V, GND, Tach, PWM)  
3. ถ้าไม่แน่ใจ → ต่อเฉพาะ +12V และ GND ก่อน พัดลมจะหมุนทันทีโดยไม่ต้องใช้ Tach/PWM

⚠️ ข้อควรระวัง
- อย่าใช้ไฟเกิน 12V เพราะแม้สเปคบอกว่า Control Voltage ได้ถึง ~13.2V แต่การจ่ายไฟเกินอาจทำให้มอเตอร์เสียหาย  
- กระแสสูงสุด ~0.37A → ถ้าใช้หลายตัวพร้อมกันควรตรวจสอบว่าแหล่งจ่ายไฟรองรับได้  
- ถ้าอยากใช้ฟังก์ชัน PWM หรือ ARGB ต้องมี คอนโทรลเลอร์/ฮับของ Tsunami หรือเมนบอร์ดที่รองรับ

เข้าใจแผนแล้วครับ คุณกำลังจะทำเป็น ชุด Spot Welder Z99 + แบต HotRock 12V 20Ah + คาปาซิเตอร์ช่วยรับพัลส์ + ระบบระบายความร้อนในกล่องอะคริลิก และอยากให้เปลี่ยนค่าตามชนิดแถบนิกเกิล/แผ่นโลหะได้ง่าย ๆ

จากรูป ผมแยกให้เป็น 3 ส่วนก่อน เพราะมีจุดหนึ่งที่ ไม่ควรต่อรวมกันตรง ๆ

1. แบต 12V 20Ah + คาปาซิเตอร์

ทำได้ที่จะต่อคาปาซิเตอร์ ขนานกับแบต แต่ผมไม่แนะนำให้เอาคาปา PCB สีทองจำนวนมากต่อเข้ากับแบตโดยตรงแล้วปล่อยให้ชาร์จทันที

เหตุผลคือถ้าคาปาเป็น 0V:

แบต 12V
  +
  │
  ├───────────── Z99
  │
  └── คาปาซิเตอร์
         0V → 12V
         ↑
       กระแสกระชากสูงมาก

อาจเกิด ประกายไฟ / ขั้วร้อน / สายร้อน / เครื่องชาร์จตัด / หน้าสัมผัสเสีย ได้

ถ้าจะทำจริง ผมแนะนำแบบนี้

┌────── Z99 ──────┐
              │                 │
12V Battery ──┼──── Capacitor ──┤
              │                 │
              └── Fuse ─────────┘

แต่เพิ่ม วงจร Pre-charge ก่อน ให้คาปาค่อย ๆ รับไฟ แล้วจึง bypass ตัวต้านทานด้วยรีเลย์/MOSFET

แบบนี้ปลอดภัยกว่าการต่อคาปาใหญ่ตรง ๆ มาก

2. คาปาสีทองจาก PCB คอม ใช้ได้ไหม?

ใช้ช่วยได้ แต่ไม่ควรคาดหวังว่าจะทำหน้าที่เป็นแบตสำรองของ Z99 ได้

พวกคาปาสีทองที่ถอดจากเมนบอร์ดมักเป็นพวก Low-ESR electrolytic / polymer capacitor ซึ่งเหมาะกับการกรอง ripple และช่วย transient

ตัวอย่างที่ผมจะเลือก:

ค่า	แรงดัน	ความเหมาะสม

470µF	25V	ดีสำหรับกรอง
1000µF	25V	ดี
2200µF	25V	ดีมาก
3300µF	25V	ดี
4700µF	25V	ดีสำหรับทำ bank เล็ก


ถ้ามีหลายตัว ต่อขนานกันได้

เช่น

4700µF + 4700µF + 4700µF
       = 14,100µF

แต่พลังงานจริงยังไม่เยอะมากเมื่อเทียบกับแบต

ที่ 12V:

10,000µF ≈ 0.72 Joule

ดังนั้นมันช่วยรับ transient ได้ แต่ ไม่ได้กลายเป็น capacitor spot-welder bank ขนาดใหญ่

และสำหรับแบตที่ชาร์จขึ้นถึง ~14.8V ผมเลือก 25V มากกว่า 16V เพื่อมี margin เหลือครับ

3. "ใช้แบต 40% ดึงไฟมาชาร์จคาปา แล้วตอนกด Spot ให้คาปาช่วย" ทำได้ไหม?

แนวคิดถูกครับ แต่ต้องเข้าใจว่าคาปาไม่ได้สร้างพลังงานเพิ่ม

มันจะเป็นประมาณนี้:

┌──────────── Z99
        │
แบต ────┼─────────────
        │
        └── C-bank ────
              ↑
          ชาร์จจากแบต

เวลายังไม่ได้ Spot:

แบต → ชาร์จ C-bank

เวลายิง Spot:

แบต + C-bank → Z99

ข้อดีคือคาปาช่วยรับช่วงกระแสกระชากช่วงสั้น ๆ ทำให้แรงดันที่ขั้ว Z99 ตกน้อยลง

แต่ถ้าคุณใช้คาปาเป็น bank ใหญ่มาก ต้องทำ pre-charge + fuse + bleed resistor ด้วย

4. พัดลม CPU 8 เส้นที่คุณกำลังวัด

ตรงนี้ อย่าเพิ่งเอาสาย 1–4 ไปต่อรวมกัน เพราะพัดลม 8 สายมีโอกาสเป็น

ชุด Motor
4 สาย
│
├─ GND
├─ +12V
├─ TACH
└─ PWM

ชุด LED/RGB
4 สาย
│
├─ V+
├─ GND
├─ Data/Control
└─ อีกเส้นเป็น control หรือไฟอีกชุด

แต่ ผมยังไม่ฟันธงสี/ลำดับสายของพัดลมคุณ เพราะรุ่นที่มี 8 สายจำนวนมากใช้ pinout เฉพาะของผู้ผลิต

ถ้าคุณเจอชุด 4 สายของมอเตอร์

มาตรฐานพัดลม PWM 4-pin โดยทั่วไปคือ:

Pin 1 = GND
Pin 2 = +12V
Pin 3 = Tachometer
Pin 4 = PWM

ดังนั้นถ้าคุณตอนนี้รู้แล้วว่า สาย 1 กับ 2 คือ +/− ของ MT ก็ถือว่าดี แต่ สาย 3/4 ไม่ควรเอาไปจ่าย 12V จนกว่าจะระบุได้

การวัด Ω ระหว่างสาย 1–4 อย่างเดียว ไม่สามารถบอกว่าเป็น D/PWM/TACH ได้แน่นอน

ถ่ายรูป หัวปลั๊ก 8 สายให้เห็นสีสายและด้านหน้าหัวปลั๊กชัด ๆ มา ผมสามารถไล่ให้เป็น:

1 = ?
2 = ?
3 = ?
4 = ?
5 = ?
6 = ?
7 = ?
8 = ?

แล้วบอกได้เลยว่าตัวไหนต่อ 12V, ตัวไหนต่อ GND, ตัวไหนปล่อยลอย และตัวไหนเอาไปควบคุมรอบ

5. ระบบระบายความร้อนที่คุณคิดไว้ ทำได้ครับ

ผมชอบแนวคิดนี้:

┌──── CPU heatsink ────┐
อากาศเย็น →  [ CPU FAN ดูดผ่าน Sink ] → อากาศร้อน
                                      │
                                      ↓
                                DC exhaust fan
                                      ↓
                                   OUT BOX

ทำกล่องอะคริลิกได้ แต่ผมแนะนำให้ อย่าให้ลมจากพัดลมสองตัวตีกัน

ให้ CPU fan ทำหน้าที่:

ดึงอากาศผ่าน heatsink

แล้วพัดลม 3–12V อีกตัวทำหน้าที่:

ดูดอากาศร้อนออกจากกล่อง

ประมาณนี้:

AIR IN
         ↓
 ┌─────────────────┐
 │    CPU FAN      │
 │       ↓         │
 │   HEATSINK      │
 │       ↓         │
 │   HOT AIR ──────┼──→ Exhaust FAN → OUT
 └─────────────────┘

และถ้า Z99/MOSFET อยู่ในกล่องเดียวกัน อย่าปิดกล่องอะคริลิกสนิท ต้องมีช่องรับอากาศเข้าและช่องระบายออก ไม่งั้นพัดลมจะหมุนแต่ไม่มีอากาศให้แลกเปลี่ยน
