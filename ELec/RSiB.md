สรุปให้เป็นประเด็นชัด ๆ ตามที่ถามมาเลยนะ จะได้ไล่ทำงานง่าย ไม่งง

---

1️⃣ HW‑586V4 กับ LM2596 ที่เขียน MAX 3A หมายความว่ายังไง
3A ไม่ได้แปลว่าใช้ได้ตลอดเวลา

- LM2596 (ตัวชิป)  
  - 3A = กระแส สูงสุดทางทฤษฎี
  - ใช้จริงแบบปลอดภัยควรอยู่แถว 1.5–2A
  - ถ้าไม่มีฮีตซิงก์หรือระบายอากาศ → เกิน 2A ร้อนเร็วมาก

- HW‑586V4 (ทั้งโมดูล)  
  - ข้อจำกัดจริงอยู่ที่  
    - คอยล์ (Inductor)
    - ไดโอด Schottky
    - ลายทองแดงบน PCB
  - โมดูลจีนส่วนใหญ่ เกิน 2A ต่อเนื่อง = อายุสั้น

📌 สรุป  
> ห้ามเกิน 3A ทั้งฝั่ง IN และ OUT  
> และถ้าใช้งานต่อเนื่อง แนะนำ ไม่เกิน 2A

---

2️⃣ ตัว R เซรามิก (R50m / R ชันต์) คืออะไร และเปลี่ยนยังไง
ตัวนี้ ไม่ใช่ R ธรรมดา

- R50m = 0.05Ω
- หน้าที่คือ วัดกระแส / จำกัดกระแส
- มักอยู่ในภาคป้องกันหรือ feedback

ถ้าจะเปลี่ยน
ห้ามใช้ R คาร์บอน / R ฟิล์มเล็ก ๆ แทนเด็ดขาด

ใช้แทนได้:
- R ชันต์โลหะ (Metal Shunt)
- R เซรามิกกำลังสูง
- ค่าใกล้เคียง 0.047Ω / 0.056Ω

กำลังวัตต์:
- อย่างต่ำ 1W
- แนะนำ 2–3W ขึ้นไป

📌 ดึงจากปริ้นเก่าได้จาก:
- PSU ทีวี
- อินเวอร์เตอร์
- เพาเวอร์แอมป์
- ไมโครเวฟ (ภาคจ่ายไฟ)

---

3️⃣ หา IC 78L05 จากปริ้นเก่ามาใช้ได้ไหม
ได้ และมักจะดีกว่าของจีนใหม่บางตัวด้วย

- 78L05 = 5V 100mA
- ใช้เลี้ยง MCU / Logic / Op‑Amp

หาได้จาก:
- บอร์ด DVD
- ทีวีเก่า
- เครื่องเสียง
- PSU เล็ก ๆ

📌 ถ้าโหลดเกิน 100mA  
→ ใช้ 7805 + ฮีตซิงก์ หรือ  
→ ใช้ Buck 5V จะเย็นกว่า

---

4️⃣ ไล่วงจรยังไงให้รู้ว่าตัวไหนทำหน้าที่อะไร
วิธีไล่แบบช่างซ่อมจริง

1. เริ่มจากไฟเข้า
   - B+ / VIN → ไดโอด → คอยล์ → IC
2. หา Regulator
   - 78L05 / Buck → ไล่ไป MCU / จอ / Logic
3. ดู R ค่าเล็กผิดปกติ
   - R50m / R ต่ำกว่า 1Ω = วัดกระแส
4. ดู Opto / Op‑Amp
   - PC817 / LM358 = ภาคป้องกัน / Feedback

📌 เทคนิค  
> ถ้า R ต่ำ ๆ วัดแล้ว “มีเสียงดัง 0Ω”  
> ยังไม่เสียเสมอ ต้องดูว่ามันเป็น Shunt หรือ Fuse‑Resistor

---

สรุปสั้น ๆ
- 3A = ค่าสูงสุด ไม่ใช่ใช้งานจริง
- R เซรามิกต้องใช้ R ชันต์กำลังสูงเท่านั้น
- 78L05 จากปริ้นเก่าใช้ได้ดี
- ไล่วงจรเริ่มจากไฟ → Regulator → ภาคควบคุม

ถ้าจะให้ผมช่วย ชี้ตำแหน่งบนบอร์ดว่าตัวไหนคืออะไรทีละจุด บอกได้เลยว่าบอร์ดไหนกำลังซ่อมอยู่ จะไล่ให้ตรงจุดมากขึ้น
