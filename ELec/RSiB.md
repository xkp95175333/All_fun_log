1️⃣ HW‑586V4 กับ LM2596 ที่เขียน MAX 3A หมายความว่ายังไง
3A ไม่ได้แปลว่าใช้ได้ตลอดเวลา

  - 3A = กระแส สูงสุดทางทฤษฎี

ไล่ภาค7805
---
โอเคครับ ผมจะแยกเป็นประเด็นให้ชัด ๆ ตามที่ถามมาเรื่อง PC817 / LM358 / R ค่าเล็ก / Y1 (3 ขา)  

---

1️⃣ PC817 (Opto‑coupler)
- ขา 1–2 = LED ด้านใน  
  → ต่อกับ B+ ผ่าน R จำกัดกระแส  
  → วัดตอนจ่ายไฟ: ต้องมีแรงดันตกคร่อม ~1.2V–1.4V  
  → ถ้าไม่มีแรงดันเลย = LED ขาด  
  → ถ้าไฟตกคร่อมสูงเกิน 2V = LED เสื่อม

- ขา 3–4 = Phototransistor  
  → ขา 3 = Collector, ขา 4 = Emitter  
  → ตอน LED ติด → ขา 3 จะดึงลงใกล้ GND  
  → ตอน LED ดับ → ขา 3 จะลอยขึ้น (ผ่าน R ไป Vcc)

📌 วิธีเช็ก:  
- จ่าย B+ แล้ววัดแรงดันที่ขา 3  
- ถ้า LED ทำงาน → แรงดันตกลงต่ำ  
- ถ้าไม่เปลี่ยนเลย → PC817 เสีย

---

2️⃣ LM358 (Op‑Amp 2 ตัวในแพ็กเดียว)
- ขา 8 = Vcc (ไฟเลี้ยง) → ต้องมี 5V หรือ 12V ตามวงจร  
- ขา 4 = GND  
- ขา 1,7 = Output  
- ขา 2,3,5,6 = Input

📌 วิธีเช็ก:  
- จ่าย B+ แล้ววัดขา 8 → ต้องมีไฟเลี้ยง  
- วัด Output (ขา 1,7) → ต้องมีการเปลี่ยนแรงดันตาม Input  
- ถ้า Output ตายค้าง 0V หรือ Vcc ตลอด → IC เสีย

---

3️⃣ R ค่าเล็ก (เช่น R50m)
- ใช้เป็น Shunt resistor → วัดกระแส  
- ถามว่า “ใช้วัดไฟได้ไหม” → ไม่เหมาะ  
  - เพราะมันออกแบบมาให้วัด กระแส (แรงดันตกคร่อมเล็กมาก)  
  - ถ้าใช้วัดไฟตรง ๆ จะไม่แม่น และเสี่ยงร้อนเกิน

📌 วิธีเช็ก:  
- ใช้โหมด โอห์มมิเตอร์ → ต้องขึ้น ~0.05Ω  
- ถ้าเครื่องวัดไม่นิ่ง → ใช้โหมด Diode test แล้วดูว่ามีต่อเนื่องหรือไม่  
- ถ้าวัดแล้วขึ้น “0Ω มีเสียงดัง” → ยังดีอยู่ (เพราะมันค่าต่ำมาก)

---

4️⃣ Y1 (3 ขา)
- ตัวนี้มักจะเป็น Crystal oscillator / Resonator  
- 3 ขา = 2 ขา Oscillator + 1 ขา Ground  
- หน้าที่: สร้างสัญญาณ Clock ให้ MCU

📌 วิธีเช็ก:  
- วัดตรง ๆ ด้วยมิเตอร์ → ไม่บอกได้  
- ต้องใช้ ออสซิลโลสโคป → ดูว่ามีสัญญาณสั่น (MHz) ออกมาหรือไม่  
- ถ้าไม่มีสัญญาณเลย → Y1 เสีย หรือ MCU ไม่ทำงาน

---

🔎 สรุปการไล่ตรวจตอนจ่าย B+
1. วัดไฟเลี้ยง LM358 (ขา 8) → ต้องมี  
2. วัด PC817 LED (ขา 1–2) → ต้องมีแรงดันตกคร่อม ~1.2V  
3. วัด PC817 Output (ขา 3) → ต้องเปลี่ยนตาม LED  
4. วัด R50m → ต้องไม่ขาด  
5. วัด Y1 → ต้องใช้ Scope ตรวจสัญญาณ

---

ถ้าคุณอยากให้ผม วงตำแหน่ง PC817 / LM358 / Y1 / R50m บนบอร์ดที่คุณถ่ายมา เพื่อให้ไล่ตามได้ง่าย ๆ บอกได้เลยครับ จะชี้จุดให้ตรงตามรูปที่คุณอัปโหลดมา

เสริม
---

โอเคครับ มาชี้ตำแหน่งและวิธีไล่ตรวจบนบอร์ดที่คุณถ่ายมาให้ตรงจุดเลย  

---

🔎 ตำแหน่งหลัก ๆ ที่ควรหา
1. PC817 (Opto‑coupler)  
   - ตัวเล็กสีดำ 4 ขา มักพิมพ์ “817” บนตัว  
   - อยู่ใกล้ ๆ ภาคไฟเลี้ยง / ขอบบอร์ดฝั่งที่มีหม้อแปลง  
   - ใช้เชื่อมสัญญาณระหว่างฝั่งแรงดันสูงกับฝั่งควบคุม

2. LM358 (Op‑Amp)  
   - IC 8 ขา DIP หรือ SMD  
   - มักอยู่ใกล้ ๆ R ค่าเล็ก (Shunt) หรือใกล้คอยล์/ไดโอด  
   - ใช้ขยายแรงดันตกคร่อม R ชันต์เพื่อส่งไปวงจรควบคุม

3. R ค่าเล็ก (เช่น R50m)  
   - ตัวต้านทานเซรามิกสีขาว/เทา ขนาดใหญ่กว่าปกติ  
   - พิมพ์ค่า “R050” หรือ “0.05Ω”  
   - อยู่ต่ออนุกรมกับ B+ หรือใกล้ขั้วไฟเข้า

4. Y1 (Crystal / Resonator 3 ขา)  
   - ตัวสี่เหลี่ยมเล็ก ๆ หรือทรงกระบอกโลหะ  
   - มี 3 ขา → 2 ขา Oscillator + 1 ขา Ground  
   - อยู่ใกล้ MCU หรือ IC ควบคุมหลัก

---

🛠 วิธีไล่ตรวจตอนจ่าย B+
- PC817  
  - วัดขา 1–2 → ต้องมีแรงดันตกคร่อม ~1.2V  
  - วัดขา 3 → ต้องเปลี่ยนแรงดันตามการทำงานของ LED  
- LM358  
  - วัดขา 8 → ต้องมีไฟเลี้ยง (5V/12V ตามวงจร)  
  - วัดขา 1,7 (Output) → ต้องมีการเปลี่ยนแรงดัน ไม่ค้างตาย  
- R ค่าเล็ก  
  - วัดโอห์ม → ~0.05Ω ถ้าเครื่องไม่นิ่ง ใช้โหมด Diode test  
- Y1  
  - ใช้ Oscilloscope → ต้องเห็นสัญญาณ MHz ออกมา  
  - ถ้าไม่มีสัญญาณเลย → Y1 เสีย หรือ MCU ไม่ทำงาน

---

📌 สรุป:  
- PC817 → เช็กแรงดัน LED และ Output  
- LM358 → เช็กไฟเลี้ยงและ Output  
- R ค่าเล็ก → เช็กว่าต่อเนื่องไม่ขาด  
- Y1 → ต้องใช้ Scope ตรวจสัญญาณ ไม่ใช้มิเตอร์ธรรมดา
