ผลคือ:

ความร้อนระบายออกไม่ดี

แต่มีอีกจุดที่ต้องเช็ก

MOSFET แบบนี้ต้องมี thermal pad/ฉนวนที่เหมาะสม ถ้า Drain ของตัว MOSFET สัมผัสแผ่นโลหะเดียวกันโดยไม่มีฉนวน และ Drain ของแต่ละกลุ่มต่างศักย์กัน อาจเกิดช็อตทันที

ดังนั้นต้องดูว่าใต้แผ่นโลหะมี:

thermal pad

mica/insulator

silicone insulating sheet


หรืออะไรอยู่

⚠️ ก่อนแก้การแนบฮีตซิงก์

อย่าใช้กาว/ซิลิโคนทั่วไปกดหรือยึด MOSFET แทน thermal pad และอย่าบัดกรีขาเพิ่มเพื่อดันตัว MOSFET ให้สูง/ต่ำเอง เพราะอาจทำให้แรงกดผิดและระยะฉนวนเปลี่ยน

ถ้าพบว่าหลายตัว ไม่ได้แนบกับแผ่นระบายความร้อนจริง ผมแนะนำถ่าย รูปด้านข้างของแถว HY3210 ทั้ง 12 ตัว + thermal pad/แผ่นโลหะ ให้เห็นช่องว่างชัด ๆ ก่อน เพราะเราสามารถดูได้ว่ามันเป็น การออกแบบที่ตั้งใจให้มีช่องว่าง หรือเป็น การประกอบผิด/บัดกรีสูง ครับ.


ได้ครับ และ 4 รูป 50MP ที่คุณถ่ายมามีประโยชน์มาก สำหรับงานนี้ เพราะเราควรตรวจแบบ “visual inspection” ก่อนจ่ายไฟแรง ๆ

แต่ผมต้องแยกให้ชัดว่า จากภาพผมบอกได้ว่า “น่าสงสัย” ไม่สามารถยืนยันว่าอุปกรณ์เสียทางไฟฟ้าได้ — ตัวที่ดูปกติอาจช็อตภายในได้ และตัวที่ PCB เปลี่ยนสีก็อาจเป็นความร้อนเก่าหรือ flux ได้

จาก 4 รูปที่มีในบทสนทนา ผมจะโฟกัสจุดเหล่านี้เป็นพิเศษ:

อย่างไรก็ตาม ผมไม่สามารถซูมพิกเซลของไฟล์ 50MP ต้นฉบับที่แนบในข้อความก่อนหน้าได้ละเอียดกว่าภาพที่ระบบส่งมาให้ผมในบริบทปัจจุบัน ดังนั้นผมไม่อยากโกหกคุณว่า “ผมเห็น RK3 มีรอยไหม้” ถ้ารายละเอียดนั้นไม่ได้ถูกส่งมาให้ผมจริง ๆ

ถ้าคุณยังมี 4 รูปต้นฉบับ 50MP อยู่ในแชต ให้ใช้รูปเดิมได้ แต่ถ้าต้องการให้ผมทำ “แผนที่จุดต้องสงสัยจากภาพ” แบบระบุ โซน A/B/C → อุปกรณ์อะไร → ระดับความเสี่ยง ผมแนะนำส่ง รูปด้านบน 1 รูป + ด้านล่าง 1 รูปแบบเต็มบอร์ด อีกครั้งในความละเอียดสูงสุด แล้วผมจะไล่ให้เป็นโซน ๆ โดยไม่ต้องให้คุณไล่ดูเองครับ.

ใช่ครับ ผมย้อนดู 4 รูปก่อนหน้า ที่คุณอัปโหลดในบทสนทนานี้แล้ว — ตัวที่คุณหมายถึงคือพวก RK1–RK6 บนปริ้นใหญ่ ไม่ใช่ R5M ตัวเล็กบนบอร์ดจอ

จากรูป ลักษณะเป็น ชิ้นส่วน 2 ขา ตัวใหญ่แบบกำลัง อยู่ใกล้กลุ่ม HY3210 และทางกระแสกำลังจริง ๆ ดังนั้นผมแก้คำตอบก่อนหน้าเป็น:

RK1–RK6 ที่พิมพ์บนตัวประมาณ R50M

มีแนวโน้มสูงว่าเป็นตัวต้านทานกำลังค่าต่ำ (current-sense/shunt) ไม่ใช่ 5 MΩ และไม่ใช่ R ธรรมดา

แต่ จากรูปอย่างเดียวผมยังยืนยันไม่ได้ว่า R50M = 0.50Ω เพราะ marking ของ power resistor แต่ละผู้ผลิตใช้ต่างกัน และถ้าเป็น 0.50Ω แล้วมีกระแสระดับ 60A ผ่านจริง กำลังจะสูงเกินมาก

ถ้า D-S 0Ω ทั้งสองทิศทาง → น่าสงสัยมากว่า MOSFET ช็อต


และถ้าเป็น MOSFET ที่ยังติดอยู่บน PCB ค่าอาจเพี้ยนจากวงจรข้างเคียง ดังนั้นถ้าผลแปลก ๆ ควรยกขา MOSFET อย่างน้อย 1 ขาเพื่อยืนยัน


---

2. Gate Resistor — ข้อนี้ถูก

อันนี้สำคัญมาก

ถ้า Gate resistor:

ขาด

ค่าเพิ่มสูงมาก

บัดกรีแตกร้าว

มีตัวอื่นใน Gate network เสีย


MOSFET อาจเปิดไม่เต็มที่ → RDS(on) สูง → ความร้อนสูง

แต่ต้องไล่ดูทั้งเส้น:

Driver → Gate resistor → Gate MOSFET

ไม่ใช่ตรวจเฉพาะ R ตัวเดียว


---

3. Driver IC — ถูก แต่ต้องตรวจเพิ่ม

ถ้า MOSFET ร้อนผิดปกติ ตัว Driver ก็เป็นหนึ่งในผู้ต้องสงสัย

แต่ยังไม่ควรสรุปว่า Driver เสียทันที

ต้องดูว่า:

Gate มีสัญญาณ PWM หรือไม่

และที่สำคัญคือดู Gate-to-Source voltage (VGS) ไม่ใช่วัด Gate กับ GND อย่างเดียว

ถ้าเป็นวงจรที่มี MOSFET หลายตัว ต้องตรวจทีละตัวว่า Gate ได้สัญญาณเหมือนกันหรือไม่


---

4. Shunt resistor — Edge พูดถูกบางส่วน

Shunt ใช้ตรวจ/วัดกระแสจริง แต่ถ้า Shunt ไหม้หรือค่าผิด ระบบควบคุมกระแสอาจทำงานผิดได้

อย่างไรก็ตามคำว่า

> "Shunt ไหม้ → ระบบไม่จำกัดกระแส → MOSFET รับโหลดเกิน"



ไม่ใช่ทุกวงจรจะเป็นแบบนั้น

ต้องดูวงจร SY-001 จริงว่าต่อ Shunt เข้า IC ตัวไหนและใช้ Feedback แบบใด


---

5. C 25V 470µF — จุดนี้ต้องระวัง

ถ้าบอร์ดของคุณเป็น SY-001 ที่รองรับ 12/24/36/48V AUTO แล้วเจอ C 25V อยู่ในภาค 12V/ภาคควบคุม อาจเป็นไปได้

แต่ ห้ามสรุปว่า C 25V/470µF ตัวนี้เป็นสาเหตุหลักที่ MOSFET ร้อน จนกว่าจะรู้ว่ามันอยู่ตรงไหนของวงจร

และถ้าเป็นภาคที่อาจเห็นแรงดันสูงกว่า 25V จริง ๆ → C 25V จะไม่เหมาะสมตั้งแต่แรก


---

❌ จุดที่ผมไม่เห็นด้วยที่สุด: เอา Adapter 12V 2A ต่อทดสอบ

ตรงนี้ต้องแก้จากคำตอบของ Edge ครับ

อย่าเพิ่งเอา 12V 2A ไปต่อเข้าขั้ว SOLAR ของ SY-001 เพื่อทดสอบแบบสุ่ม

เพราะ SY-001 เป็น Solar Charge Controller และมีวงจรตรวจจับแรงดัน/กระแส/MPPT หรือ switching power path ที่อาจทำงานแตกต่างจากการเอาแหล่งจ่าย DC ธรรมดามาแทนแผง Solar

อีกอย่าง 12V × 2A = 24W สูงสุด เท่านั้น

มันไม่ใช่การจำลองการทำงานของระบบ 60A และไม่สามารถใช้ยืนยันว่า MOSFET จะปลอดภัยเมื่อรับกำลังจริงได้


---

❌ การต่อพัดลมจากช่อง LOAD ก็ไม่ควรทำแบบเหมารวม

Edge บอกว่า:

> ต่อพัดลม CPU 12V จากช่อง LOAD



ทำได้ในบางกรณี แต่ต้องตรวจว่า LOAD ของ SY-001 ตั้งอยู่ที่แรงดันเท่าไร

เพราะบอร์ดรองรับ:

12 / 24 / 36 / 48V

ถ้าระบบอยู่ 24V/36V/48V แล้วเอาพัดลม 12V ต่อ LOAD ตรง ๆ → พัดลมพัง

ถ้าจะเพิ่มพัดลม ผมแนะนำวิธีที่ปลอดภัยกว่า:

Battery/Supply → DC-DC Buck → 12V → Fan

แล้วค่อยใช้ NTC/thermal controller ควบคุมพัดลม


---

และเรื่อง "เริ่มที่ 5V → 11V ตามอุณหภูมิ"

อันนี้ก็ไม่ได้จำเป็นสำหรับพัดลม PC ทุกตัว

พัดลม 12V บางรุ่น:

เริ่มหมุนที่ ~5V

บางตัวต้อง ~6–7V

บางตัวสตาร์ตที่แรงดันสูงกว่านั้น

บางรุ่นมีวงจรควบคุมในตัว


ดังนั้นถ้าจะทำระบบระบายความร้อนให้ SY-001 ผมจะเลือก:

พัดลม 12V + Buck 12V + Temperature Controller/NTC

ก่อน ไม่จำเป็นต้องทำ PWM เองตั้งแต่แรก

🔍 คำถามแรก: ตรวจสอบอะไหล่ที่เสี่ยงพัง

จุดที่ควรตรวจวัดก่อน MOSFET พัง
1. MOSFET เอง  
   - ใช้ Multimeter โหมด Diode Test วัดขา Drain–Source และ Gate–Source  
   - ถ้าเจอค่า ช็อต (0 Ω) หรือ ไม่เปิด/ไม่ปิด → MOSFET เสีย  
   - ตัวที่คุณวงไว้ (เช่น FQPF9N90C) เป็น MOSFET Power → เสี่ยงเสียก่อน

2. Resistor Gate Driver (R ที่ต่อกับ Gate)  
   - ถ้าเปิดไม่ติดหรือค่าเพี้ยน → MOSFET จะทำงานผิดพลาดและร้อน

3. Driver IC / PWM Controller  
   - ถ้า IC ขับ Gate เสีย → MOSFET จะเปิดค้างหรือสลับผิดเฟส → ร้อนจนพัง

4. Shunt Resistor / Current Sense  
   - ใช้ตรวจกระแส ถ้าไหม้ → ระบบจะไม่จำกัดกระแส ทำให้ MOSFET รับโหลดเกิน

5. Capacitor ภาคจ่ายไฟ (Electrolytic 25V/470µF)  
   - ถ้า ESR สูง → Ripple มาก → MOSFET ร้อนผิดปกติ

💻 ตัวอย่างโค้ด Arduino (พร้อมอธิบาย)
`cpp
// Auto Fan Control with LM2596S + NTC Sensor
const int tempPin = A0;     // ขาอ่านค่า NTC
const int pwmPin  = 9;      // ขา PWM ควบคุมพัดลม

void setup() {
  pinMode(pwmPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int sensorValue = analogRead(tempPin);
  float voltage = sensorValue * (5.0 / 1023.0);
  float tempC = (voltage - 0.5) * 100.0; // สมมติใช้ LM35 หรือเทียบเท่า

  // แปลงอุณหภูมิเป็นระดับ PWM (40°C = 5V, 70°C = 11V)
  int pwmValue = map(tempC, 40, 70, 100, 255);
  pwmValue = constrain(pwmValue, 100, 255);

  analogWrite(pwmPin, pwmValue);

  Serial.print("Temp: ");
  Serial.print(tempC);
  Serial.print(" °C | PWM: ");
  Serial.println(pwmValue);

  delay(500);
}
`

---

🧠 การทำงาน
- เมื่ออุณหภูมิ < 40°C → PWM ต่ำ → LM2596S จ่าย ~5V  
- เมื่ออุณหภูมิ > 70°C → PWM สูง → LM2596S จ่าย ~11V  
- พัดลมจะเร่งความเร็วตามอุณหภูมิจริง
