# สรุปข้อมูลอุปกรณ์ semiconductor และแนวทางการต่อวงจรปรับรอบมอเตอร์ DC

เอกสารนี้จัดทำขึ้นเพื่อเป็นคู่มือสรุปสเปคของไอซี/ทรานซิสเตอร์/ไดโอด ในภาพถ่าย [cite: 1, 2, 3, 4] โดยเรียงลำดับตามประสิทธิภาพ/คุณสมบัติ และแนวทางการเลือกใช้งาน Linear Regulator / PWM Regulator สำหรับมอเตอร์ DC

---

## 1. ตารางสเปคอุปกรณ์ Semiconductor ในภาพ (เรียงตามสเปค/คุณสมบัติ)

ตารางนี้รวบรวมรหัสที่อ่านได้จากเบอร์อุปกรณ์บนแผ่นทดลอง [cite: 1, 2, 3, 4] โดยแบ่งตามประเภทการใช้งานหลัก:

### Group A: Power MOSFET / Power Transistor (สำหรับการขับโหลด / สวิตช์)

| เบอร์อุปกรณ์ (Part No.) | ชนิด / แพ็กเกจ | สเปคสูงสุด (V / A / W) | จุดเด่น & ความต้านทาน ($R_{DS(on)}$) | การนำไปประยุกต์ใช้ในวงจรนิยม |
| :--- | :--- | :--- | :--- | :--- |
| **W19NC50 (STW19NC50)** | N-Channel MOSFET (TO-247) [cite: 1, 2] | 500V / 19.1A / 220W | High Voltage, $R_{DS(on)} \approx 0.23 \Omega$ | วงจร Switching Power Supply (SMPS), วงจร High-Voltage DC |
| **K3451 (2SK3451)** | N-Channel MOSFET (TO-220F) [cite: 1, 4] | 600V / 12A / 35W | High Voltage Isolation | วงจร switching supply ฝั่งฝั่งไฟสูง High-side |
| **K D998 (2SD998)** | NPN BJT Power Transistor (TO-3P/TO-247) [cite: 1, 2, 3] | 120V / 10A / 80W | High Power BJT, $h_{FE} \approx 55-160$ | วงจรขยายเสียง (Power Amp), Linear Motor Drive |
| **TIP41C** | NPN BJT Power Transistor (TO-220) [cite: 3, 4] | 100V / 6A / 65W | Standard Medium Power NPN | วงจร Switch ขับมอเตอร์เล็ก/รีเลย์, Linear Voltage Regulator Pass Transistor |

---

### Group B: Schottky Barrier / Fast Recovery Rectifiers (ไดโอดเรกติไฟเออร์ High-Current)

| เบอร์อุปกรณ์ (Part No.) | ชนิด / แพ็กเกจ | สเปคสูงสุด (V / A) | Forward Voltage ($V_F$) | การนำไปประยุกต์ใช้ในวงจรนิยม |
| :--- | :--- | :--- | :--- | :--- |
| **SBL3040PT** | Dual Schottky Diode (TO-247) [cite: 1, 3, 4] | **40V / 30A** (15A/leg) | **~0.55V** (สูญเสียพลังงานต่ำมาก) | **Flyback / Freewheeling Diode คร่อมมอเตอร์กระแสสูง**, Rectifier ไฟ DC |
| **SBL2040CT** | Dual Schottky Diode (TO-220AB) [cite: 1, 2, 3] | 40V / 20A (10A/leg) | ~0.55V | Freewheeling Diode, Rectifier ในพาวเวอร์ซัพพลายคอมพิวเตอร์ |
| **STPR1620CT** | Dual Ultra-Fast Diode (TO-220AB) [cite: 1, 2, 3] | 200V / 16A (8A/leg) | ~0.99V (Fast Recovery) | Freewheeling Diode สำหรับมอเตอร์ที่ใช้ PWM ความถี่สูง |

---

### Group C: Fast Rectifiers / General Power Diodes

| เบอร์อุปกรณ์ (Part No.) | ชนิด / แพ็กเกจ | สเปคสูงสุด (V / A) | จุดเด่น | การนำไปประยุกต์ใช้ในวงจรนิยม |
| :--- | :--- | :--- | :--- | :--- |
| **FME-230 / FHE-230** | Dual Fast Recovery Diode (TO-220) [cite: 2, 4] | 300V / 20A | High Voltage Fast Recovery | วงจร Rectifier ฝั่ง Output ของ Switching Transformer |
| **CET (CEB/CEP Series)** | MOSFET/Diode Package [cite: 1, 2, 3] | ขึ้นอยู่กับเบอร์ย่อย (~40V-100V, 15A-30A) | Low Thermal Resistance | วงจรควบคุมกำลังไฟ DC |

## 2. การเลือกใช้ไอซีปรับแรงดัน/ปรับรอบสำหรับ มอเตอร์ GRC 550V (2S-21V)

### 📌 บริบทแรงดันและกระแส
- **มอเตอร์:** GRC 550V รองรับแรงดันตั้งแต่ 2S (7.4V) ถึง 21V
- **แหล่งจ่ายไฟที่มี:** DC 18V / 3.14A (ประมาณ 56.5W)
- **ความต้องการ:** ปรับแรงดันตั้งแต่ **3–4V ไปจนถึงสูงสุด (18V)** เพื่อปรับรอบความเร็วอย่างครบถ้วน

---

### ⚠️ คำเตือนสำคัญเรื่อง Linear Regulator (ตระกูล LM)
หากใช้ไอซี Linear Regulator (เช่น **LM317**, **LM338**, **LM317T**) ปรับแรงดันไฟขับมอเตอร์ขนาดใหญ่อย่าง 550:
1. **ความร้อนสูงมาก (Power Dissipation):** เมื่อจ่ายไฟ 18V ออก 4V ให้กระแส 3A ตัวไอซีต้องทนการสูญเสียพลังงานในรูปความร้อนสูงถึง:
   $$P_D = (V_{in} - V_{out}) \times I = (18V - 4V) \times 3A = 42 \text{ Watts!}$$
   ซึ่งไอซีตระกูล LM จะไหม้หรือตัดการทำงานจาก Over-Temperature ทันทีแม้จะใส่ฮีตซิงก์ใหญ่ก็ตาม
2. **กระแสกระชากช่วง Start-up:** มอเตอร์ 550 ขณะเริ่มหมุน (Stall / Start) ใช้กระแสสูงถึง **10A – 20A+** ซึ่งทำให้ไอซี Linear ตัดการทำงานทันที

---

### 💡 คำแนะนำและตัวเลือกที่เหมาะที่สุด:

#### [วิธีที่ 1] แนะนำที่สุด: ใช้ PWM DC Motor Speed Controller (ไม่ใช้ Linear LM)
วงจร **PWM (Pulse Width Modulation)** ปรับความเร็วด้วยการตัดต่อสัญญาณความถี่ ไม่ใช่การลดแรงดันในรูปความร้อน
- **ไอซีสร้างสัญญาณ:** สามารถใช้ **LM555** (Timer IC) สร้างสัญญาณ PWM ร่วมกับ **N-Channel Power MOSFET** (เช่น **IRFZ44N**, **STW19NC50** [cite: 1, 2] หรือ **IRF1404**)
- **การทำงาน:** ปรับรอบได้ตั้งแต่ 0% – 100% (จ่ายแรงดันเฉลี่ยตั้งแต่ ~1V ถึง 18V เต็ม) โดยไม่เกิดความร้อนสะสมที่ไอซี
- **วงจรป้องการกระชาก:** ใช้ไดโอด **SBL3040PT** [cite: 1, 3, 4] หรือ **SBL2040CT** [cite: 1, 2, 3] (จากในรูปที่มีอยู่) ต่อ **Freewheeling/Flyback Diode** คร่อมขั้วมอเตอร์ เพื่อป้องกันแรงดันย้อนกลับ (Back-EMF) ทำลาย MOSFET

#### [วิธีที่ 2] หากต้องการใช้ตระกูล LM แบบปรับแรงดันจริง (Linear Buck)
- **LM338T / LM338K:** ไอซีปรับแรงดัน 5A (จ่ายชั่วขณะได้ 7A) แรงดัน Output 1.2V - 32V
- **LM317 + TIP41C / Power Transistor Pass Element:** ใช้ LM317 เป็นตัวคุมแรงดันร่วมกับ Transistor ขนานขับกระแส
- *ข้อจำกัด:* ต้องติด **Heat Sink ขนาดใหญ่มากๆ พร้อมพัดลมระบายอากาศ**

---

## 3. การอัพเกรดเครื่องเจียร์มินิ (Mini Grinder) ไปใช้มอเตอร์ RS380

### 📌 วิเคราะห์สเปคเดิมและแหล่งจ่ายไฟ
- **สเปคแหล่งจ่ายเดิม:** DC 12V / 13W ($pprox 1.08	ext{ A}$)
- **ความต้องการของมอเตอร์ RS380:**
  - แรงดันทำงาน: 12V DC
  - กระแสขณะไม่มีโหลด (No-load): ~0.4A – 0.8A
  - กระแสขณะทำงาน/ภาระงานหนัก (Working/Stall): **3A – 8A+**

---

### ❓ คำถาม: ต้องเปลี่ยนแหล่งจ่ายไฟเดิมหรือไม่? ทำ A/V เพิ่มจากเดิมได้ไหม?
> **คำตอบ:** **ต้องเปลี่ยนแหล่งจ่ายไฟใหม่ครับ** 
> ไม่สามารถ "ขยาย" หรือ "เร่ง" กระแส (Ampere) จากหม้อแปลง/อะแดปเตอร์เดิม 12V 13W ให้กลายเป็น 2A–5A โดยไม่เปลี่ยนหม้อแปลงได้ เนื่องจากกฎการอนุรักษ์พลังงาน ($P = V \times I$) อะแดปเตอร์เดิมจ่ายพลังงานได้สูงสุดเพียง 13 วัตต์เท่านั้น

---

### 🛠️ แนวทางการเลือกแหล่งจ่ายไฟและตัวควบคุม (LM) สำหรับ RS380

1. **เลือกแหล่งจ่ายไฟใหม่:**
   - **ขั้นต่ำ:** อะแดปเตอร์ **12V 3A - 5A** (36W - 60W) ขึ้นไป เพื่อรองรับแรงบิดช่วงเจียร์ชิ้นงานโดยรอบไม่ตก
   - หากใช้ **12V 2A** [ตามที่สอบถาม]: สามารถใช้งานเจียร์งานเบาๆ ได้ แต่งานหนักอาจมีอาการรอบตกหรือพาวเวอร์ซัพพลายตัด

2. **การเลือกไอซีปรับรอบ (LM) สำหรับ RS380:**
   - **ตัวเลือกที่ 1 (PWM Controller - แนะนำ):** ใช้ **LM555** วงจร PWM ร่วมกับ MOSFET (เช่น IRFZ44N / IRF540) สามารถปรับความเร็วรอบได้เรียบเนียนตั้งแต่ 0-100% Efficiency สูง ความร้อนต่ำมาก
   - **ตัวเลือกที่ 2 (Linear Regulator):** ใช้ **LM338** (5A) หรือ **LM1084 / LM1085** (Low Dropout 3A/5A) ปรับแรงดัน 1.25V–12V แต่ต้องติดตั้งแผ่นระบายความร้อนด้วย

   * 2SD998 (K D998) (120V / 10A / 80W): BJT Power Transistor ทนกระแสได้สูง เหมาะทำวงจรขยายกำลัง/ขับมอเตอร์
   * TIP41C (100V / 6A): NPN Transistor มาตรฐานสำหรับขับสวิตช์หรือร่วมกับวงจร LM317

 * คำแนะนำ: มอเตอร์เบอร์ 550 กินกระแสช่วงกดโหลดหรือ Start-up สูงมาก (10A–20A+) หากใช้ไอซี Linear Regulator เช่น LM317 หรือ LM338 จ่ายไฟ 18V ดรอปเหลือ 3–4V ความร้อนสะสมจะสูงถึง 40-50 วัตต์ ส่งผลให้ไอซีไหม้หรือตัดการทำงานทันที

   * ต่อไดโอด SBL3040PT คร่อมขั้วมอเตอร์ 550 เพื่อป้องกันความเสียหายจากแรงดันย้อนกลับ
