### 6\. เรื่อง UVC ที่ถามมา

รองรับตามสเปกกล่อง Capture

คำที่ถูกต้องคือ UVC (USB Video Class) ไม่ใช่ UVA

* UVC = มาตรฐานที่ทำให้ Windows มองอุปกรณ์เป็นกล้อง USB

* UAC = มาตรฐานเสียง USB

* OTG = ความสามารถของมือถือในการทำหน้าที่เป็น USB Host เพื่อใช้อุปกรณ์ USB ภายนอก

Vivo Y17s รองรับ USB-C และ OTG ตามสเปกทางการ แต่ไม่ได้ระบุ DisplayPort Video Output ดังนั้นอย่าเพิ่งซื้อสาย USB-C to HDMI มาเพิ่ม เพราะ OTG ไม่ได้หมายความว่ามือถือส่งภาพ HDMI ออกได้ vivo Thailand
